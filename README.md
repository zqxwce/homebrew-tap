# zqxwce/homebrew-tap

Homebrew tap for [`vphone-cli`](https://github.com/Lakr233/vphone-cli) — boot a
virtual iPhone via Apple's Virtualization.framework.

```bash
brew install zqxwce/tap/vphone-cli
```

This installs the `vphone-cli.app` and puts the `vphone-cli` command on your
PATH. The tool requires SIP/AMFI relaxed and a few extra tools — see the cask
caveats (shown on install) and the [project README](https://github.com/Lakr233/vphone-cli).
